## Content Templates

### Template Variables (per page type)

**Comparison (`/vs/`):**
- `{competitor}` — Name
- `{competitor_price}` — Their price
- `{competitor_weakness}` — Main weakness
- `{savings}` — $ saved with PlayCourt
- `{migration_time}` — Time to switch

**Audience (`/for/`):**
- `{audience}` — Segment name
- `{pain_1}`, `{pain_2}`, `{pain_3}` — Top 3 pains
- `{feature_1}`, `{feature_2}` — Relevant features
- `{testimonial}` — Quote from that segment
- `{club_count}` — "Join X+ {audience} clubs"

**Use Case (`/use-case/`):**
- `{problem}` — Problem name
- `{stat}` — Key statistic
- `{before}` — Before state
- `{after}` — After state
- `{how_it_works}` — 3-step explanation

**Location (`/tennis-booking/[city]`):**
- `{city}` — City name
- `{state}` — State
- `{tennis_facts}` — Local tennis scene (courts, clubs, weather)
- `{nearby_cities}` — Related locations
